## RoomFlow – Hotel Management SaaS Platform

RoomFlow is a comprehensive hotel management application built with React Native, designed to streamline hotel operations through three dedicated interfaces: **Admin, Staff, and Guest**.

The platform simplifies hotel management by integrating room and booking management, guest services, staff operations, and revenue analytics into a unified mobile experience.

### Key Features
- **Multi-Role Architecture:** Dedicated Admin, Staff, and Guest panels with role-specific functionality.
- **Booking Management:** Manage the hotel booking lifecycle and maintain consistent booking states across different panels.
- **Real-Time Notifications:** Custom Firebase Cloud Messaging (FCM) notification engine using Google's FCM HTTP v1 API.
- **Revenue Analytics:** Interactive dashboards for monitoring hotel performance and revenue.
- **Data Export:** Generate and export revenue reports in PDF and Excel formats.
- **Offline Data Management:** WatermelonDB integration for local data persistence.
- **Modern UI:** Responsive interface with persistent Dark and Light themes.
- **Production Optimization:** Android release builds with Hermes engine, ProGuard optimization, and Android API 35 compatibility.

### Technology Stack
React Native CLI, JavaScript, Firebase Firestore, Firebase Cloud Messaging (FCM), WatermelonDB, jsrsasign, Hermes, and native Android tooling.

**Project Goal:** Build a scalable, mobile-first hotel management solution that reduces operational complexity and connects hotel administrators, staff, and guests through a unified platform.
